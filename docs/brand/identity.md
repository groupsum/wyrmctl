# wyrmctl / Portwyrm brand identity

**Name:** wyrmctl

**Product family:** Portwyrm

**Tagline:** Safe declarative proxy host automation for Nginx Proxy Manager.

**Positioning:** wyrmctl is Portwyrm operator CLI and Python extension surface for teams that want GitOps-style Nginx Proxy Manager automation without silent overwrites, unmanaged adoption, or global pruning.

**Audience:** platform engineers, DevOps engineers, homelab operators, SREs, and software architects operating Portwyrm and Nginx Proxy Manager behind Docker and GitHub Actions.

**Voice:** precise, operational, security-conscious, and implementation-first.

**Core promise:** Portwyrm and wyrmctl create only what is safe to create and refuse everything else.

**Compatibility note:** `npmctl` is a compatibility-facing profile and downstream distribution. Native Portwyrm documentation should use `wyrmctl`, `wyrmctl.com/v1`, and `meta.managed_by: wyrmctl`.
